# Лабораторна 1: ООП на Python

Кіберспортивна ліга

Демонстрація принципів ООП на прикладі моделювання кіберспортивних змагань.

## Ієрархія класів

Абстрактний клас `Competitor` визначає загальний інтерфейс для учасників змагань. Від нього успадковуються `Team` (команда з ростером гравців) та `SoloPlayer` (індивідуальний учасник). Обидва перевантажують метод `get_summary()`, додаючи власну специфіку.

Клас `Player` містить базову інформацію про гравця (нікнейм, вік, країна). `Match` моделює поєдинок між двома учасниками зі збереженням рахунку. `Tournament` агрегує матчі та спонсорів.

## Елементи ООП

- Приватні властивості: `_rating` у Competitor, `_score` у Match — доступ через геттери/сеттери
- Перевантаження: `get_summary()` у Team додає капітана, у SoloPlayer — країну
- Посилання на об'єкти: Match зберігає посилання на двох учасників
- Колекції: `roster` (список гравців у команді), `sponsors` (список спонсорів турніру)
