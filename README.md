# Лабораторна 2: Глобали IRIS

Кіберспортивна ліга

Робота з глобальними змінними InterSystems IRIS для зберігання даних про матчі.

## Структура глобала

```
^match(tournament, year, rating, match_id, key) = value
```

Чотири рівні індексів різних типів: назва турніру (string), рік (int), рейтинг матчу (decimal), ID (int). На останньому рівні два ключі: `"p"` для гравців та `"m"` для метаданих.

## Два типи списків

Рядковий список через роздільник — зберігає гравців та рахунок у форматі `"player1/player2/score"`. Розбирається функцією `$PIECE`.

Системний список `$ListBuild` — зберігає назву гри та timestamp. Елементи витягуються через `$LISTGET`.

## Функції роботи з глобалами

Використано `$DATA` для перевірки існування, `$GET` з дефолтним значенням, `$ORDER` для обходу всіх турнірів, `$QUERY` для повного обходу дерева, `$NAME` для отримання канонічного імені, `$PIECE` та `$LISTGET` для роботи зі списками.

Всі дані вводяться з клавіатури через `Read`, нічого не захардкожено.
